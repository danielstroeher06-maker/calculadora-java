 🧮 Calculadora Java

Calculadora completa desenvolvida em Java do zero, com operações básicas, funções científicas e histórico rotativo.

---

 ✨ Funcionalidades

- ➕ **Soma, subtração, multiplicação e divisão**
- 🔢 **Potência** (`Math.pow`)
- √ **Raiz quadrada** (`Math.sqrt`)
- 📊 **Porcentagem** (2 modos: x% de y / quanto % x representa de y)
- 🔬 **Funções científicas** (seno, cosseno, tangente, logaritmo)
- 📜 **Histórico rotativo** dos últimos 5 cálculos
- ✅ **Tratamento de erros** (divisão por zero, raiz de número negativo, entrada inválida)

---

 🚀 Como executar

 Pré-requisitos
- Java JDK 17 ou superior
- IntelliJ IDEA (recomendado)

 Passos
1. Clone o repositório:
```bash
git clone https://github.com/danielstroeher06-maker/new-repository.git
```

2. Abra o projeto no IntelliJ IDEA

3. Execute a classe `calculadora.java`

---

 🖥️ Como usar

Ao executar o programa, um menu interativo será exibido:

```
===  CALCULADORA ===
1. SOMA
2. SUBTRAÇÃO
3. MULTIPLICAÇÃO
4. DIVISÃO
5. POTÊNCIA
6. RAIZ QUADRADA
7. PORCENTAGEM
8. FUNÇÕES CIENTÍFICAS
9. VER HISTÓRICO
0. SAIR

Escolha uma operação:
```

Digite o número da operação desejada e siga as instruções na tela.

---

 📚 Conceitos utilizados

| Conceito | Onde foi aplicado |
|---|---|
| `Scanner` | Leitura de entrada do usuário |
| `while` loop | Menu interativo contínuo |
| `if/else if` | Seleção de operações |
| `try/catch` | Tratamento de entradas inválidas |
| `Arrays` | Histórico rotativo de cálculos |
| `Math` class | Potência, raiz, funções trigonométricas |
| `double` | Precisão em divisões e cálculos decimais |
